# LoveConnect - Dating App

LoveConnect is a modern dating application built with Flutter and Firebase.  
It allows users to create profiles, explore matches, chat in real-time, and build meaningful connections.  
The app is designed with a clean UI and smooth performance to make dating simple and secure.  

## ✨ Features
- User registration & login with Firebase Auth  
- Profile creation with photos and bio  
- Real-time chat and notifications  
- Swipe & match system  
- Secure data handling  

## 🚀 Getting Started
1. Clone this repository  
2. Run `flutter pub get`  
3. Add your Firebase config files:  
   - `android/app/google-services.json`  
   - `ios/Runner/GoogleService-Info.plist`  
4. Run the app with:  
   ```bash
   flutter run
